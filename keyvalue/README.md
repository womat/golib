# keyvalue

> **Deprecated:** keyvalue moved to its own module,
> [github.com/womat/keyvalue](https://github.com/womat/keyvalue), with the same API —
> change the import path. It is removed from golib in v2.

A `map[string]any` with converting typed accessors. The code here stays
unchanged until v2; documentation, tests and further development are in
[github.com/womat/keyvalue](https://github.com/womat/keyvalue#readme).

```go
import "github.com/womat/keyvalue" // instead of github.com/womat/golib/keyvalue
```
